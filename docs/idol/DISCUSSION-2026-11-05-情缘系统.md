## 零、总原则

- 全新系统，完全不考虑旧存档。
- 男主是谁不固定，**六种类型 + 必触发节点固定**。每次新档遇见不同的人。
- 玩家 = Flora 本人，讨论时用「你」，别说「她」。
- 恋爱后节点**暂不设计**，她明确说过。

## 二、男主怎么产生

- 世界生成人物时**不预设每类人数配额**，谁是什么背景自然长出来，AI 按剧情让她结识。
- 结识 ≠ 男主。她看中谁，**通讯录加「关注」** → 他进入对应类型的线，成为该线男主。
- **一条线同时只有一个人**；其他同类人照常认识相处，但不进线。
- **不能换人**——关注即定，羁绊值跟这个人走，后面遇到再对味的也不换。
- 关注按钮：通讯录人物页，**只有身份属于六类之一的人才显示**；按钮只写「关注」不标类型（防剧透，不然电竞线掉马前就露了）；一条线被占后，同类型其他人不再显示按钮。
- 关注 = 线开启，**羁绊值从关注那一刻开始计**，关注前的相处不算线进度。

## 三、羁绊值

- 有效互动：此刻一次连续私下见面 +5（连续待一整天只算一次）；电话/视频 +3（**每日上限计一次**，文档里没设上限，本窗口堵的洞）；一次有来有回 KKT 私聊 +1（每世界日上限 +2）。
- 羁绊值**只管要不要触发固定剧情**。他喜不喜欢你是十档关系（跟你过不去…恋人）+ 心动线的事，三把尺子各管各的，不做同步。
- 门槛：**四节点线 12 / 28 / 48 / 72**；**五节点电竞线 12 / 25 / 40 / 58 / 78**。
- 节奏实测推算（她点头说合理，待实测微调）：六线并行约一个月上下全到最后一档；六个男主在世界里相遇时间不同，自然错开。
- 设计意图：第一个门槛低（纯聊天一周内也开第一场戏，不会卡在聊天里）；台阶逐级变大，走到最后一场必须靠持续见面（见一两次只开第一场）。
- 门槛到 = 节点**待触发**，还要等合适场景，数值不会一天爆两场。

## 四、行动点

- 每日 08:00–24:00，共 8 点，**1 点 = 2 小时**，统一标准。
- 占点的只有：上课、加练、约会。**KKT、电话不占点**；24 点之后（晚上挂机）不占点、没人管。
- **课表全改整格**（8-10、10-12 这种），不出现半点、不出现错开（她明确否掉 5-7 这种）。
- 上课**大改**（见第五节）。
- 加练：点「加练」那一刻扣 1 点（今晚九点两小时），取消退点，一天一次照旧。
- 约会：**至少扣 1 点**（哪怕只待十分钟）；每满 2 小时再扣 1 点；两小时到了弹「继续约会？」，继续就接着扣，结束就结账。**没有 0.25 点**（她否了）。
- 扣点跟活动本身走，跟她花几分钟读戏无关。
- 点数用完点进此刻：**照常打开**，消息、电话、动态都可用（本来不花钱）；安排见面时提示「今天的时间排满了」；只能发消息、打电话、睡觉——睡到明早 8 点刷新满 8 点。此刻顶部显示「今天还剩 X 点」。

## 五、上课大改（重要，她反复强调）

- 不再自动判定出席，**必须她主动**：课表时间，她在此刻里人出现在公司（比如练习室）= 上课。
- **迟到 30 分钟内不算旷课**；到点人不在公司 = 旷课。
- 上课戏内容：**AI 写好的固定剧情池**（「今天老师教了 XXX」…结尾结属性值，+5 是格式示例，**具体走训练系统结算**）。
- 属性值加完之后：挂了剧情就自动触发（**事业主线 / 同期随机剧情**两类）；没挂剧情就到此结束。
- 退出此刻 = 2 小时过去、扣 1 点，哪怕她一分钟就读完了。
- 同期随机剧情池 = 掉马第二半「同期拉你看比赛」的载体（公司正常训练期间）。

## 六、节点触发方式（三分）

每个节点带一个触发标记：

1. **invite（他先动）**：他发 KKT / 打电话约你，你接了才进戏。演唱会邀请、MV 邀请、密室、篮球赛、庆典、职业比赛、双排、宴会、画报、汉江泡面等。
2. **encounter（机会自然发生）**：羁绊到门槛后代码查世界事实（有没有路演日程、他有没有驻唱、他人在不在首尔），合适机会出现，场景里自然发生。路演偶遇、酒吧驻唱、街角擦肩（伏笔）。
3. **event（事情砸过来）**：前置条件满足，事情找上门。私生骚扰、绯闻曝光+公司谈话、出道受挫。

硬要求：encounter 型必须**世界真的提供这些机会**——路演日程、驻唱安排、比赛行程作为世界事实存在，不能凭空蹦出来（对应她文档里「需要游戏世界提供真实的路演机会」）。

## 七、多线并行的世界反应

- **不另做系统**，沿用家里恋情隐私规矩（`lib/idol-romance.ts` ROMANCE_PRIVACY_RULE）：无明确来源就不知道；普通同行、吃饭、约会不构成发现；不在场不目击；私下知情 ≠ 公司知情 ≠ 粉丝媒体知情；传播必须在剧情里实际发生。
- 平时六线并行互不知情很安全；谁在剧情里被真实看见/曝光，知情链才启动——其他男主来问、吃味、退一步，韩网起热帖，公司约谈。**曝光事件就是反应开关**，系统不凭空添乱。

## 八、告白

- 必触发节点走完之后，**谁先开口都行**：他告白、你告白、都不告白就这么暧昧着，全自然发生。
- 不设固定机制、不设门槛、不限制。羁绊值不代表爱情，系统不替她决定交往。

## 九、双向掉马（电竞线节点 3）

**第一半：他先发现你（固定）**

- 公司拍摄练习生练习视频并**真实上传**（视频真实出现在她世界的 YouTube app 里，她能刷到、能看评论，不是凭空）。
- 他**自己刷到**（渠道自由、和她无关：自己刷到 / 队友甩群里 / 粉丝转发——她否掉了「她发链接给他」，那等于自曝）。
- **场外短幕**展现「他知道了」：深夜他的房间，他点开、重播、呆住。她全程看见，他不知道——戏剧反讽。
- 之后他怎么做**自由**：可能当场打电话、装没事人、直球问、憋到死。AI 按人设演，不写剧本。

**第二半：你先发现他（固定）**

- 公司正常训练期间，一个同期好朋友拉她一起看比赛直播；她听到选手里有一个声音和他一模一样，打的还是他天天和她打的那款游戏。
- 「哪个朋友」不固定：引擎按同期里谁最沾边挑（电竞迷 / 游戏迷 / 动漫宅 / 热络百事通），没人沾边就安排「给你看超火视频」的路子。**不要求同期池里必须有电竞迷，不设硬配额。**
- 她亲历，不用切镜头。之后她怎么做自由（质问 / 装不知道 / 憋着）。

**共同规矩**

- 两半的顺序**不定死**，谁的条件先凑齐谁先发生。
- 掉马前 **AI 严禁泄露他的职业身份**，谁漏了重来。
- **街角擦肩伏笔必须回收**：双方都见过对方的脸，先掉的一方认出那一刻就是「原来那天街上的人是你」。
