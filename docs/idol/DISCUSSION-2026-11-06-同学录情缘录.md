# 同学录 + 情缘录（一个 app）内容定稿（2026-11-06）

> 内容已定，界面等她发大概的样子。之前四版预览（previews/yearbook/）全被否：前三版太卡通，v4 跟星路太像。

## 同学录（39 名女同期，一人一页；没有玩家自己的页）

- 基本：姓名、年龄、生日、国籍、身高
- 一眼印象：外貌、性格
- 背景：家庭背景、TMI（每人 1～2 个独有小细节）
- 实力：特长、当前班级（和养成数值对得上）
- MBTI：只给她看，AI 只判断一次，不喂给角色
- 关系档位：沿用十档
- 我的印象：只有她自己写，系统不提炼、不代写，空着就空着
- 关系事件：只记客观发生的事
- 室友：只在她室友的页上标「室友」，其他人不显示宿舍号
- 她的朋友圈（同期之间的好朋友/朋友/熟人）
- 月考排名 + 每月升降班记录
- 相关同期支线的记录
- 退社的同期也留页（显示已离开）

## 情缘录（六条线）

- 没关注的线：不标类型
- 关注后才标这条线的类型，用英文不用中文（IDOL / UNDERGROUND / ESPORTS / HEIR / TRAINEE / CAMPUS 暂定），电竞线也一样关注即标（她自己设计的剧情，她知道）
- 已走过的节点显示标题；没走到的显示 ？？？
- 羁绊值显示当前数字，不显示门槛
- 没有「我的印象」

## 补充（同日）

- 入口：一打开是两本书并排（黑=同学录 CLASSMATES、粉=情缘录 LOVE RECORD），点哪本进哪本
- 同学录：属性八项写数字（每次打开读名册最新值，NPC 一周结算一次）；档案用表格式（LOOKS/NATURE/FAMILY/TMI 左列）；学生证加 ENTRY；分班 A/B/C/D 四个
- 情缘录 FATE CARD：年龄/生日/国籍/身高/MBTI（读通讯录同一份资料）+ MET（认识那天，不要关注那天）+ LINE + BOND；外貌性格留通讯录，卡片放 PROFILE → 跳过去
- 情缘录加 BETWEEN US 十档圆点；CHAPTERS 按线定义的节点数自动排（她以后可能加节点）
- 预览：previews/yearbook/v6-card.html（同学录）、romance-v2.html（情缘录+入口）
