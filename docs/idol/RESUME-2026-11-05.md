## 3. 本窗口踩的坑（重要）

1. **dev server 必须带 `NEXT_PUBLIC_SELF_HOSTED_MODE=true`**，否则停在账号登录页（Supabase 未配置 503）。正确启动：`NEXT_PUBLIC_SELF_HOSTED_MODE=true npx next dev -p 3001`。
2. **dev 模式不要用 `NEXT_DIST_DIR`**：相对路径落在 repo 内 → watcher 看到自己产物无限重编译；绝对路径被 next.config.mjs 转成项目外相对路径 → 页面 500 `MODULE_NOT_FOUND next/dist/compiled/...`。dev 用默认 `.next` 即可；build 验证用 `NEXT_DIST_DIR=private/tmp/<名字> npx next build`（相对路径，build 无 watcher 问题）。
3. next.config.mjs 里 Codex 加的绝对路径转换对 build 有用，保留。
4. Next 构建会自动往 tsconfig.json 写 distDir 的 types include——构建完记得 `git checkout -- tsconfig.json` 恢复，别带进提交。
5. 构建产物 private/tmp/ 很大（2GB），本窗口已删。tsconfig 已恢复。
6. 3001 端口还跑着一个 dev server（PID 在 /tmp/idol-melon-dev.pid，日志 /tmp/idol-melon-dev.log），本窗口启动的，供测试/截图用。3031 未动。
7. 测试里 Open App 用 `window.postMessage({type:"OS_CMD", action:"open_app", appId:"melon"}, "*")`；Melon 的评论区/播放器/详情页没有底栏，回首页要连点顶部返回。
