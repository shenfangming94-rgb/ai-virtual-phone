## 0. 她为什么要这个

练习生的基本东西都做完了，但现在的生活全靠她自己推：开局选的特长、家境、公司，选完就只是练习生证上几个字，后面没有因为它们变得不一样。
她想要的是**游戏感**：每天有事、有收获、有惊喜，搞事业很爽，出道苦尽甘来。
- **不要**变成「更多剧情」——她明确说过「这个还是剧情」不对
- **不要**她自己引导才发生；也**不要**提前写死的情节，要 AI 到时候现场发展，才有惊喜
- **无论怎么选都有不一样的精彩，没有哪个选择才是正确的**

## 2. 等级 A / B / C / D / F

### 2.1 起点
- 开局特长格子里**她点过的那几门从 B 开始，没点的从 D 开始**（10-29 她改的：要有晋升空间）
- 门类：照练习生证特长格子现有的那几门（`lib/trainee-card.ts` 的 talents / TALENT_ZH），别另起一套

### 2.2 最重要的规矩：等级只跟她自己比
- 等级表示的是「她比原来的自己强了多少」，**不是**她和别人比的水平
- 从 B 到 A 不代表以前不够好，可能她本来就是最好的，A 只是更好了
- 她的真实水平由她自己在此刻里怎么写决定，**等级不能限制她**
- 所以：**绝不能把「她舞蹈是 C」这种绝对档位写进给 AI 的提示**，否则 AI 会预设她跳得差、让老师说她不如别人、要多练。她最怕这个（「不爽文」「开局低谷憋屈」）
- AI 只能知道**变化**：比如「最近她舞蹈明显进步了」「最近她声乐有点退步」
- 大家只对**升了/退了**有反应，不对本来的等级有反应

### 2.3 怎么升降（10-29 定，全由代码算；AI 只报「这段练的是哪门、表现 good/ok/bad」，升不升它说了不算）
- 门类改名：「写歌」显示为**创作**（英文 Creation）。成绩单八门：Vocal 唱歌 / Dance 跳舞 / Rap / Creation 创作 / Acting 演技 / Variety 综艺感 / Language 语言 / Visual 颜值
- 每门的来源：唱跳 rap＝课、练习室加练、周评月考；创作＝作曲课、写 demo、作曲家工作室；演技＝演技课、内部短片、试镜；综艺感＝公司 vlog/YouTube、团建游戏、上镜场合；语言＝语言课、和外国练习生用外语聊；颜值＝**形象管理**（造型课、皮肤管理、宣材照、镜头感），不是整容
- **表格不加东西**：点一下等级字母 → 弹小卡片「离 A 还差 N 次」+「加练」按钮（她要看得见还差多少，但不要挤在表里）
- 速度：只上课约半年一档；上课+每周作业约 3 个月；再加经常加练最快 6 周。一个月同一门最多升一档。一门两个月完全没碰退一档，最低 D
- 已有的 `idol_ledger_v1.levels`（月末排名用）**别跟这个混**，排名照旧
- 升/退一档：iOS 横幅（`lib/idol-notes.ts`）「星路 · 舞蹈升到 A 了」，点了进星路

### 2.4 谁提醒她（10-29 定）
1. **公司课表**：签约时按公司排每周课表，进提醒事项「公司日程」能看到。日常课**默认去了**，不用演不用打勾，**跳时间不停**（跳时间＝照常过日子）。只上课涨得很慢
2. **老师每周作业**：每周老师 KakaoTalk 布置一个 + 进提醒事项，照旧三结局（此刻演 / 打勾写一句 / 不做）。涨得最多；照顾短板，轮着布置不同的课（颜值＝宣材照、综艺＝拍 vlog 这种）
3. **自己加练**：星路点等级字母弹出的「加练」→ 进提醒事项「我自己记的」，到点打勾写一句就算；一天最多一次。此刻里去练习室/录音室演一段，结束时 AI 判断练的哪门也算加练

### 2.5 旷课（10-29 定，看「上课那段时间人在不在公司」）
- 每节课有固定时间段。到点看她在干嘛：
  - 什么都没做 / 跳时间跳过 → 上了
  - 此刻里地点在**公司**（练习室、录音室、食堂都算）→ 上了
  - 公司安排的事撞上（试镜、拍摄、内部评估、叫去办公室）→ 公假，等于上了
  - 请假且老师批了 → 不涨不罚
  - 此刻里地点**不在公司** → 旷课
  - 答应了别人的约且时间撞课，她去了（演或打勾）→ 旷课
- 防误旷：撞课的邀请上写一行小字「这个时间是声乐课」；发动机排朋友约尽量避开上课时间；此刻里上课时间去公司外的地点时提示一下。去不去她定
- 请假沿用现有：私聊管理老师 → `buildIdolChatHint` 给他看日程 → 批了回复带 `[准假:日程名]` → `leaveNode`。有了课表要补：①老师现在只看 `slice(0, 6)` 个日程，课一多就满，改成按日期列、并支持**请一整天**（那天所有课一起请）；②请假要进世界提示（室友、同期知道她今天请假/请病假在宿舍），别让人问她怎么没去上课；③老师没批她还不去 → 照旷课算
- 后果：这节不涨；第一次老师 KakaoTalk 问（沿用现有缺席 `onAbsent`）；一个月第二次起叫去办公室 + 那门进度扣一次

## 3. 命运（= 图鉴卡）

### 3.1 是什么
- 命运就是图鉴卡本身：**触发一个就翻开一张卡**
- 内容是**彩蛋**：照她平常的玩法根本碰不到、她自己也想不到、推动不起来的机会。是「怎么会是我？？」那种
- **不是**发动机里顺理成章的机会（练得好被叫去伴舞、录 demo 这种都**不算**）
- **不是**加点数：不许带「某门课 +1」「关注度 +一点」这种效果，她说太鸡肋，跟命运没关系
- 跟开局有关：家境 × 公司 × 特长 × 性格组合出来的。她举的例子（只是让你理解味道，**别写进提示词**，规矩见 HANDOFF 第 1 节「提示词不举例」）：富裕开局进 JYP 才可能认识某人被邀请去巴黎看时装秀；普通开局进 SM 才可能因为便利店打工遇到一个前辈或者一个很有资源的人
- 每种开局分到的数量一样多，只是味道不同；**不决定能不能出道**

### 3.2 生成
- **签公司时**（`signCompany`，`lib/idol-career.ts`）一次 AI 调用生成 **8 个**：读练习生证（家境、特长、性格等）+ 签的公司
- 分三种（10-29 她定）：**大 2 个**（改变这段日子走向、牵出几个月的线）、**中 3 个**（练习生圈外的重要的人或新圈子，来往几周）、**小确幸 3 个**（分量小但温暖、记很久）。她不要「很怪」这种说法，怕画风跑偏。大和中必须是一扇门能接着走。跟发动机平常会排的事（`ENGINE_EVENTS`）重了或换个说法都不算。让 AI 想十二个挑八个
- **练习生时期就这 8 个，之后不补**（10-29 她改的：怕通货膨胀；出道后的彩蛋以后再说）
- 每个命运存：卡片标题（几个字）、一句种子（给触发时的 AI 看）、触发条件、来法、相关的人（可以是新捏的）
- 清单**她看不到**

### 3.3 触发条件
- AI 从**代码给的菜单**里选类型（例如：到某个世界日期/季节、某门课升到某档、和某人关系到某一步、去过某地点几次、关注度到某档……菜单由实现者定，条件都要代码能判断）
- **代码管节奏**：不能全挤在一个月，也不能半年一个不来
- **保底**：世界时间大约三周没触发任何一个，就挑最接近满足的那个直接推（跟 IdolSearch 的 forced 保底一样）

- 10-29 加的条件（她要跟「某一类人」有关，不指定具体哪个人）：people（关系到某步的某类人几个，可限 MBTI 字母、身份词、男女）、dated（谈过几次恋爱）、rank（月末前几/最后几）、season（某个月/她生日前后）、after（进出道组、有人离开公司、选拔没进以后）。time 约三分之一，跟人有关的多用

### 3.4 来法（她定的，只有这两大类）
1. **KakaoTalk**（主要）：陌生人加她、认识的人突然私聊、群里有人@她、管理老师单独找、家里人发消息等
2. **此刻地图上的感叹号**：某个地点钉子上冒「!」，点进去不用选、直接开演（种子交给此刻开场）。冒出来时**发 iOS 横幅**提醒，例如「此刻 · 江南好像有什么不一样」
- **不要**：未接来电/短信（没有这个 app）、YouTube 评论区（太小众）、邮箱怪信（她没懂、删了）

### 3.5 触发以后
- 种子 + 她当下处境 → AI 现场发展（聊天走现有聊天引擎，见 HANDOFF 2.32）
- 要她去哪儿/见谁 → 进提醒事项，照旧三结局：此刻演 / 打勾写一句 / 不去（缺席）
- **去不去卡都翻开**
- 感叹号挂**一周世界时间**，没点就消失，卡照样翻开
- **跳时间跳不过去**：命运到点要进 `capJump`（`lib/idol-reminders.ts`）停下，像 `plannedStops`、`yearlyStops` 一样；停下之后她不理、接着跳，算她自己选了不去

### 3.6 卡片（10-28 夜定稿，素材在 `docs/idol/mockups/destiny/`）
- 卡上**只写几个字**，例如「巴黎时装秀」。**不写过程、不写结尾**，不要两段
- **没翻开**：一律用 `card-locked.png`（她给的暗红玫瑰「Spring is sweet. Love is sweet.」）**原样，不改任何东西**，不加字不加编号
- **翻开**：照 `album-v1.html` / `fronts-v1.png`：她给的奶黄卡背 `card-front-source.png` 上抠出来的白线玫瑰层 `card-front-light.png` + 顶部深色星点层 `card-front-dark.png`，换底色；左上角 `No.01` 小编号；下方中文标题（Noto Serif SC/思源宋体 700，字距 .18em，#2b2a25）+ 一行手写体英文（Mrs Saint Delafield，微斜）
- **标题外面不要圈**（她明确去掉了）
- 底色轮流用：#E4E0AA 奶黄、#E8CBC5 雾粉、#C9DCC6 薄荷、#C6D4E0 雾蓝、#D4CCE1 薰衣草、#EBD4B6 杏、#CCD3B2 鼠尾草、#DED6CB 灰米
- 英文那行 AI 生成卡片标题时一起给
- 图鉴页显示「已遇见 3 / ？」；八张一页（两列四排），以后多了往后翻页
