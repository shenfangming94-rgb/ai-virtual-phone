# 练习生时期：会发生的事（10-27 和她讨论定的，待她过目）

## 定下来的规矩
- 事情不弹「触发了 XX 事件」。三种来法：有人告诉你（KakaoTalk 私聊/群）、有时间点的进提醒事项、戏里自然碰上（世界知道「最近正在发生的事」）
- 不替她决定表现、身体以外的状态、心情；她的失误类事件换成发生在别人身上
- 她自己做过的事才有后果（偷吃了才可能被抓，交了歌才有被否/进 demo）
- 频率：两三天一件小事，一两周一件大事；她生病几个月一次
- 提醒事项每项三种结局：去演 / 打勾写一句（算真发生过） / 过了开始时间两小时没动 = 缺席（有后果）
- 请假：KakaoTalk 给管理老师发消息，老师批了才自动「已请假」；玩得好的人之后来关心；也能直接左滑请假（不走 API）
- 关注度（看不见）：童星/星二代/财阀开局高；普通开局低，靠公开视频、伴舞、路透涨；粉丝舆论类事件按关注度出现
- 生病：室友/同期发 KakaoTalk 发现，或下一场戏开头写；病期记在她身上
- 前辈团全部虚构
- 日历只留她自己的（去掉 char 日历；宿主 char 日历本来就要手动生成，不会自己动）：提示大事记，能自己记、也能让 AI 写
- 提议（待她回）：主要人物加「最近在忙什么」，事件发生时更新、平时世界隔一阵刷新，聊天和戏里都带上
- 选秀节目支线：搁置；猫：不出现

## 事件清单（给她过目的版本）

### 一、找上你的事（外面的人对你做的，你决定怎么接）
- 训练：老师叫你去办公室（夸你/提醒你/通知你）、舞蹈或声乐老师留你加课、被选为小组长、临时换 part、编舞征集、自作曲征集、外聘老师来上课、新开的课（镜头表情管理/礼仪/语言）、内部评估（社长或制作人来看）、高层视察、概念适配测试、定位调整面谈
- 机会：练习生公开视频挑人、给前辈伴舞、前辈来练习室指导、MV 客串、广告/网剧/综艺试镜、杂志拍摄、校园公演、公司年末演唱会练习生上台
- 宿舍：卫生检查、宿舍搬迁、换室友、断电/空调坏/洗衣机坏、拼单奶茶、快递丢了、新规矩（门禁、收手机）
- 生活：生日惊喜、节日聚餐、团建、匿名交换礼物、跨年加练
- 粉丝（看关注度）：粉丝信、礼物、公开视频底下的留言、路透被拍、上热搜、恶评、谣言、有人嗑你和同期的 CP
- 身体（很少）：感冒发烧、肠胃炎、过敏、扭伤、生理期不舒服

### 二、别人身上的事（你旁观或掺和）
- 同期：月考忘动作哭着回宿舍、破音被点名、体重被约谈、节食晕倒、受伤、偷点外卖被抓、门禁迟到、手机被收、礼仪课罚站
- 关系：吵架冷战和好、室友打呼/抢浴室/晾衣服纠纷、谁暗恋谁、有人被孤立、谁被老师偏爱惹人不满
- 人来人往：新练习生进来、淘汰夜、有人自己放弃走了、被挖去别的公司
- 八卦：出道组名单传闻、谁偷偷谈恋爱被发现
- 重的（少）：霸凌谣言、匿名信、家人病倒、心理崩溃——只发生在别人身上

### 你的挫折（一个月一两次，从外面来，不写你没做好，怎么应对由你）
- 普通开局：被关系户抢位置、抢 part、抢机会
- 财阀/富二代/星二代：网上说靠家境进来、没实力，同期背后议论
- 童星：被说小时候更可爱、过气了，被拿来跟小时候比
- 谁都可能：被嫉妒、人际矛盾、被孤立；关注度高了有黑粉、私生

### 三、你做过的事的后果
- 缺席 → 老师私聊、约谈、补考；请假 → 有人关心、补考
- 交了编舞/自作曲 → 被采纳、被否、进 demo
- 戏里偷吃/晚归/偷用手机 → 可能被抓
- 跟谁走得近 → 他更常来找你；得罪了谁 → 他可能使绊子（有具体原因）
- 考核表现 → 排名、机会多少

### 四、往出道走（按开局填的「练多久」排）
月末排名 → 出道组传闻 → 内部选秀 → 名单泄露 → 定成员（可能补位进、也可能被移出）→ 定位置、C 位竞争、part 分配 → 定队名 → 录出道曲 → 出道预热 → 出道

### 五、大事记（日历）
- 写死的：春节、中秋、圣诞、跨年、你的生日、公司年末演唱会、年末颁奖季
- AI 每月生成：虚构前辈团的回归、演唱会、巡演、粉丝见面会、综艺播出，同公司前辈的活动
- 你自己记：随便写一笔，或者让 AI 帮你写

### 六、出道后才用（先存着）
官咖、直播、采访、打歌、签售、粉丝投票、商演、私生跟车、黑热搜澄清、站姐、舞台事故（耳返失灵、服装开线、滑倒）

### 砍掉的
火灾警报、梦游、食物中毒、养宠物、暴食、家里和学校整类，以及所有替你写失误的（都挪到别人身上了）；选秀节目先搁置
