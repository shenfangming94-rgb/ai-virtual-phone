# 练习生时期：会发生的事（10-27 和她讨论定的，待她过目）

## 定下来的规矩
- 事情不弹「触发了 XX 事件」。三种来法：有人告诉你（KakaoTalk 私聊/群）、有时间点的进提醒事项、戏里自然碰上（世界知道「最近正在发生的事」）
- 不替她决定表现、身体以外的状态、心情；她的失误类事件换成发生在别人身上
- 她自己做过的事才有后果（偷吃了才可能被抓，交了歌才有被否/进 demo）
- 频率：两三天一件小事，一两周一件大事；她生病几个月一次
- 提醒事项每项三种结局：去演 / 打勾写一句（算真发生过） / 过了开始时间两小时没动 = 缺席（有后果）
- 请假：KakaoTalk 给管理老师发消息，老师批了才自动「已请假」；玩得好的人之后来关心；也能直接左滑请假（不走 API）
- 关注度（看不见）：童星/星二代/财阀开局高；普通开局低，靠公开视频、伴舞、路透涨；粉丝舆论类事件按关注度出现
- 生病：室友/同期发 KakaoTalk 发现，或下一场戏开头写；病期记在她身上
- 前辈团全部虚构
- 日历只留她自己的（去掉 char 日历；宿主 char 日历本来就要手动生成，不会自己动）：提示大事记，能自己记、也能让 AI 写
- 主要人物加「最近在忙什么」（她同意）：一场戏演完随记账一起更新、事件发生时更新、一周没动的世界每周批量刷新、她也能改；显示在 KakaoTalk 状态消息（他自己口吻短句）+ 通讯录名片「最近」（世界视角带日期）；私聊群聊戏里都带上
- 开局页「练多久」改名「多久出道」（她误以为是进公司前练了多久）
- 年龄（她查了资料定的）：一起玩的同期 16～19；公司练习生 12～21（12～15 小练习生进群和路人）；20+ 算偏大、少见会被议论；出道一般 16～19，她过 20 没出道世界照实写压力；开局「随便」年龄改 16～19；大人不限。写进 CARD_RULES、路人、世界提示
- 选秀节目支线：搁置；猫：不出现

## 事件清单（给她过目的版本）

### 一、找上你的事（外面的人对你做的，你决定怎么接）
- 训练：老师叫你去办公室（夸你/提醒你/通知你）、舞蹈或声乐老师留你加课、被选为小组长、临时换 part、编舞征集、自作曲征集、外聘老师来上课、新开的课（镜头表情管理/礼仪/语言）、内部评估（社长或制作人来看）、高层视察、概念适配测试、定位调整面谈
- 机会：练习生公开视频挑人、给前辈伴舞、前辈来练习室指导、MV 客串、广告/网剧/综艺试镜、杂志拍摄、校园公演、公司年末演唱会练习生上台
- 宿舍：卫生检查、宿舍搬迁、换室友、断电/空调坏/洗衣机坏、拼单奶茶、快递丢了、新规矩（门禁、收手机）
- 生活：生日惊喜、节日聚餐、团建、匿名交换礼物、跨年加练
- 粉丝（看关注度）：粉丝信、礼物、公开视频底下的留言、路透被拍、上热搜、恶评、谣言、有人嗑你和同期的 CP
- 身体（很少）：感冒发烧、肠胃炎、过敏、扭伤、生理期不舒服

### 二、别人身上的事（你旁观或掺和）
- 同期：月考忘动作哭着回宿舍、破音被点名、体重被约谈、节食晕倒、受伤、偷点外卖被抓、门禁迟到、手机被收、礼仪课罚站
- 关系：吵架冷战和好、室友打呼/抢浴室/晾衣服纠纷、谁暗恋谁、有人被孤立、谁被老师偏爱惹人不满
- 人来人往：新练习生进来、淘汰夜、有人自己放弃走了、被挖去别的公司
- 八卦：出道组名单传闻、谁偷偷谈恋爱被发现
- 重的（少）：霸凌谣言、匿名信、家人病倒、心理崩溃——只发生在别人身上

### 你的挫折（约两个月一次，一年最多六次；同一种只来一次，记账；从外面来，不写你没做好，怎么应对由你）
- 同一个人不用同一招第二次，但不同人可以各有矛盾（她同意）
- 普通开局：被关系户抢位置、抢 part、抢机会
- 财阀/富二代/星二代：网上说靠家境进来、没实力，同期背后议论
- 童星：被说小时候更可爱、过气了，被拿来跟小时候比
- 谁都可能：被嫉妒、人际矛盾、被孤立；关注度高了有黑粉、私生

### 三、你做过的事的后果
- 缺席 → 老师私聊、约谈、补考；请假 → 有人关心、补考
- 交了编舞/自作曲 → 被采纳、被否、进 demo
- 戏里偷吃/晚归/偷用手机 → 可能被抓
- 跟谁走得近 → 他更常来找你；得罪了谁 → 他可能使绊子（有具体原因）
- 考核表现 → 排名、机会多少

### 四、往出道走（按开局填的「练多久」排）
月末排名 → 出道组传闻 → 内部选秀 → 名单泄露 → 定成员（可能补位进、也可能被移出）→ 定位置、C 位竞争、part 分配 → 定队名 → 录出道曲 → 出道预热 → 出道

### 五、大事记（日历）
- 写死的：春节、中秋、圣诞、跨年、你的生日、公司年末演唱会、年末颁奖季
- AI 每月生成：虚构前辈团的回归、演唱会、巡演、粉丝见面会、综艺播出，同公司前辈的活动
- 你自己记：随便写一笔，或者让 AI 帮你写

### 六、出道后才用（先存着）
官咖、直播、采访、打歌、签售、粉丝投票、商演、私生跟车、黑热搜澄清、站姐、舞台事故（耳返失灵、服装开线、滑倒）

### 砍掉的
火灾警报、梦游、食物中毒、养宠物、暴食、家里和学校整类，以及所有替你写失误的（都挪到别人身上了）；选秀节目先搁置

## 出道判定（她选 B：可能推迟，最后一定出道）
- 公司心里一本账（不显示数字）：考核（演了按表现、打勾按她写的）、缺席扣、请假不扣要补考、接下并完成的机会加、挫折本身不扣（应对捅娄子才算）、老师高层印象
- 目标出道前几个月「出道组选拔」对账：够→进组按时出道；不够→推迟，原因从账上来，几个月后再选，门槛逐次降低
- 信号：月末排名、老师私下的话、同期八卦

## 恋爱
- 公司男女都有，训练考核宿舍分开；交集：食堂、电梯、天台、便利店、公司活动、年末演唱会、合作舞台
- 公司规矩写死恋爱禁令；她可以偷偷谈，被发现的风险看她做了什么（后果类），关注度高可能被拍
- 她要「大家不那么正派」：捏人时少数（十个里一两个，男女都有）私下花心/同时吊几个/劈腿/约炮，表面不一定看得出；她照样能跟他发展，玩玩还是真心看剧情；八卦里会听到别人的这类事
- 感情线不硬塞，看剧情；偶尔有人表现出兴趣给苗头
- 每人「你还不知道的秘密」（她同意）：捏人时就定、之后不加（不能因为她喜欢上谁临时安排他花）；约三分之一有小秘密（心事、小动作、过去、瞒着的伤或家里、地下恋情），花心/关系户这类重的十个最多一两个，其余没有（偷看显示「他没什么瞒着你的」）；花的人早期会露苗头；名片「偷看秘密」随时能看；编辑页能改；剧情里撞破或听八卦后才正式显示在名片（写怎么知道的）；秘密会在剧情里起作用
- CARD_RULES 写规矩不举例（见记忆 feedback-prompt-no-examples）

## 好感（10-27 定）
- 两条线。关系：陌生→认识→熟人→朋友→好朋友，可往下（有点烦你→不喜欢你→跟你过不去），从朋友/好朋友可走暧昧→恋人（地下，有恋爱禁令），也可分手成前任。心动：没感觉→有好感→有点在意→喜欢→很喜欢
- 只在事情之后变（记账、聊了一阵后），写原因，一次最多一格；很久没交集会淡；没事不变
- 起点按「人缘」：默认「招人喜欢」（不放开局页，设置里能改）——约一半一开始有好感，一见钟情约八分之一（从喜欢起步）；普通/万人迷两档备用（普通：五分之一有好感、十五分之一一见钟情；万人迷：大部分有好感、五分之一一见钟情）
- 心动线只给：年龄跟她差三四岁以内（她未成年时卡严，成年后放宽）、且不是管她的人（管理老师、她的经纪人）；不看职业（摄影师、化妆师、粉丝、狗仔、学生、资方少爷、路上酒吧认识的都行）；女生偶尔一个（比例低很多，不纠缠，她不是拉拉但可以有女生喜欢她）
- 心动了会行动（看人设）：有点在意=找借口说话记住小事；喜欢=约你带吃的帮你说话；表白看性格（直球快、闷骚靠小动作、顾虑多会因恋爱禁令出道犹豫）；很喜欢大多迟早说出口
- 显示：关系在通讯录名片；心动藏在「偷看秘密」；私聊群聊戏里都带上态度

## 还要做的几块（10-27 讨论定）
- 时间：跳过的日子算她照常过日子。跳时只补不用回的（群通知、八卦、动态），需要她回的消息落地时才发（新鲜的，不显示成几天前没回）；世界不抱怨她失联。世界提前排好接下来几天的事（她看不到），跳到哪天，之前的补成消息，当天的实时发生；跳时间遇到提醒事项的项、或有新的「待回复」进来就停
- 提醒事项：有时间、要她本人到场的都进（周评月考约谈补考；机会先「待回复」接了才变日程；别人约你答应了也进；写谁通知的）。不进：别人的事、八卦、粉丝信、当下的意外（消息或戏里写）
- 室友：进公司第一天分一到两个室友（捏好的主要人物）
- 钱：后台调用尽量合并，加开关能看能控
- 锁屏通知：KakaoTalk 消息、待回复、日程提醒上锁屏
- 动态（原朋友圈，留在 KakaoTalk 里叫「动态」）：只有加了的人发；不按时自动发，改成近况更新时有概率顺手发（同一次调用）；跳时间批量补发、时间戳分散；练习生一周一两条；保留「让他立刻发一条」，也带近况和世界；以后 ins 再接公开号/小号
