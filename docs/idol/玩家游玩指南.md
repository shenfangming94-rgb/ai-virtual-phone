# 爱豆小手机｜新玩家游玩指南

欢迎来到你的练习生生活。爱豆小手机把韩娱成长故事装进一部可以亲手操作的虚拟手机：你从填写练习生档案开始，寻找经纪公司、参加试镜，在首尔过课业、交朋友、接通知、做选择，一步步走向出道。

这不是一条所有人都会读到相同台词的固定小说。世界会记住你的档案、关系、日程和选择；AI 会根据当时发生的事生成对话与场景。每个存档都可能走出不同的生活。

## 你会经历什么

### 从一张练习生证开始

开局填写姓名、生日、国籍、外貌、起始日期、预计练习时长、家境、特长和其他设定。特长包括唱歌、跳舞、Rap、创作、演技、综艺感、语言和颜值。你可以上传照片，也可以使用“随机”来补全部分资料。

主角目前设定为女性练习生。家庭档案由你决定：可以选双亲、单亲、其他监护人，也可以暂不设置父母或监护人；成员姓名、职业、居住地等资料都能自行编辑。没有写进档案的家人不会被故事擅自补出来。

你选的起始日期会成为故事时间的起点，时钟从当天上午 9 点开始。预计练习时长会影响出道筹备的大致节奏。

### 找公司、收邀请、参加试镜

家境会影响故事开场。星二代、富二代、财阀家和童星会遇到开局星探邀请；普通家境和自定义家境需要主动打开 **IdolSearch**，搜索公司、查看官网并提交资料。不同公司的试镜口味和世界里的艺人、团体会随故事设定展开。

邀请、投递回执和审核结果会通过手机里的提醒事项、邮箱等入口送达。接受试镜后，日程会记进提醒事项；到时间可以进入“此刻”亲自演，也可以用打勾记录完成情况，或选择不去。试镜结束后还要等公司回信；收到正式录取邮件后点“接受录取”，才算签约进入公司。

### 过练习生的日子

签约后会有公司课表、每周作业、练习室加练、周评月考和月末排名。星路会记录八门课的变化：唱歌、跳舞、Rap、创作、演技、综艺感、语言和颜值。等级主要记录你相对自己的进步，不是给你贴上“天生好或差”的标签。

课程默认参加，不需要每节课都手动打勾。老师每周布置的作业和自己安排的加练，则可以亲自演、打勾记一句当时的情况，或选择不做。课表与外出约会撞上时，记得留意提醒事项里的提示；需要请假可以在 KakaoTalk 联系室长。

除了训练，世界里也会发生朋友邀约、同学和前辈来往、生日祝福、春节与中秋安排、年末家族演唱会等事情。你可以答应、拒绝，也可以看看这件事会怎样发展。关系和感情线都不是必选内容。

### 认识身边的人，也看看圈内动态

**KakaoTalk** 是主要聊天入口，有私聊和练习生群。遇到新人物时，通讯录可以查看对方资料；如果对方把 KakaoTalk ID 给了你，通常需要自己去 KakaoTalk 添加好友，不会一律自动变成好友。

**Instagram** 和 **YouTube** 会呈现身边人的动态、公司的练习生内容和圈内反应。你也可以发布自己的内容，看看朋友、路人或粉丝怎样回应。**日历**可以查看重要日子，也能让 AI 帮你安排一周空档；**手记**可以留住自己的记录。

签约后还会开启 **星路** 里的“命运图鉴”。图鉴藏着八个根据你的开局和生活生成的机会，遇到时逐张揭晓；卡片清单不会提前剧透。

### 在“此刻”里亲自进入场景

“此刻”是地图与互动场景入口。你可以从提醒事项进入约好的试镜、课程或邀约，也可以打开地图，选择地点开始一段日常戏。进入场景后直接写你想说的话或想做的事，AI 会结合人物关系、当前时间和已有经历接下去。已结束的场景可以回看。

练习生阶段之后，主线会推进到出道选拔、组队、公布队名、录歌、拍摄和出道舞台。当前版本的重点是练习生生活与出道筹备；出道后的完整回归和活动周期还在继续扩展。

## 第一次游玩

1. **配置自己的 AI。** 打开“设置 → API 设置”，添加兼容的聊天模型接口地址、API 密钥和模型名称，并测试连接。再到“配置绑定”确认聊天、剧情等需要用到的模型已绑定。“爱豆世界（自动）”会随爱豆玩法自动附带，不需要手动再选一次。核心文字玩法需要可用的 AI 接口；图片生成、语音等属于可选功能。模型调用可能按你所用服务商的规则计费。
2. **填写练习生档案。** 从封面进入申请表，按自己的喜好完成资料。家境和特长会影响开局，但其余细节可以留白。最后签名并盖章，正式开始这个世界。
3. **查看手机通知。** 先看看 KakaoTalk、提醒事项和邮箱；如果收到试镜或其他邀请，打开详情了解时间地点，再决定接受、婉拒或回复。
4. **安排接下来的时间。** 用“时钟”推进故事时间。到重要日程时，时钟可能停下来等你处理；收到新消息或横幅时，也可以点开看看发生了什么。
5. **随时按自己的节奏玩。** 你可以认真演完整场戏，也可以把普通日程打勾略过；想体验别的开局，可以在设置的“存档”里开新档。

## 一天通常怎么玩

可以从手机上的红点和通知开始：回 KakaoTalk、读邮件、查看提醒事项。接受邀约后，把时间推进到约定时段，再点“去演”进入场景；完成日程后，可以打勾并写一句记录。空下来的时间可以上课、加练、和朋友聊天、刷动态或在地图里自由探索。睡前再看看日历和手记，决定要不要继续快进。

## 几条实用规则

- **故事时间不等于现实时间。** 练习生档案里的起始日期决定虚拟世界从哪一天开始；快进会推进故事日历，并触发相应的日程和事件。
- **预约尽量准时。** 如果提前点击“去演”，时间会推进到日程时间；约定时间之后两小时内开始，会按当前时间进入；迟到超过两小时会按缺席处理。
- **普通家境不会有开局星探邀请。** 去 IdolSearch 搜索公司并投递即可。审核需要经过故事时间；留意 IdolSearch 的投递状态和邮箱回信。
- **公司课程默认参加。** 不必逐节打勾；但课程时段离开公司去参加别的场景，可能会记为旷课。每周作业和自己安排的加练需要单独处理。
- **关系需要在故事里建立。** 有些人会先给你 KakaoTalk ID 或发好友申请；按手机里的提示添加后，才能在 KakaoTalk 继续聊天。
- **进度保存在当前浏览器。** 同一浏览器里可以管理多个存档。不要把清除网站数据当作普通清理；要换设备或留副本时，先使用设置里的数据管理/备份功能。
